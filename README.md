# Atlas

A high-performance, native command palette and launcher for Windows.

Built with Qt 6 (QML) + C++23 and a Rust indexing engine. Atlas aims for
sub-10ms toggle latency, instant full-drive file search via direct NTFS
USN/MFT enumeration, and (eventually) compatibility with the Raycast
extension ecosystem.
